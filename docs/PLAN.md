# 3D-BAT — план реализации

**Жанр:** 3D tower defense (web) с перспективой кроссплатформенного десктопа.
**Сеттинг:** мистическая пещера. Игрок защищает Великий Кристалл от волн ночных тварей, расставляя по насестам **летучих мышей-стражей**. Враги летят по 3D-пути сквозь пещеру.

---

## 1. Технологические решения

| Слой | Решение | Почему |
|---|---|---|
| Сборка | **Vite 6** + vanilla JS (ES-модули) | Ноль фреймворков, быстрые инкрементальные сборки, малый вес |
| 3D | **Three.js** (единственный runtime-зависимый пакет) | Зрелый WebGL, процедурная генерация из коробки |
| Графика | Canvas 2D → `CanvasTexture` + BufferGeometry (примитивы, шум Вернона) | Все текстуры и меши генерируются в рантайме, ноль файлов ассетов |
| Звук | **WebAudio API** — синтез осцилляторами + noise-буферами | Все sfx и музыка генерируются кодом, ноль аудиофайлов |
| Логика | Чистые ES-модули `src/core/` без зависимостей от three/DOM | Юнит-тесты под Node; ядро переносимо на десктоп (Electron/Tauri) |
| Тесты | `node --test` над чистой логикой (путь, волны, экономика, таргетинг) | Без браузера, дёшево, детерминированно |
| Десктоп (позже) | Обёртка **Tauri** (Rust, лёгкая) или Electron | Веб-сборка — это уже полноценный клиент; обёртка не меняет код игры |

**Принцип:** не устанавливать ничего тяжёлого на сервер. Runtime-зависимости — только `three` (+ `vite` как dev). Всё остальное — самописные модули.

## 2. Механики (фишки)

1. **Полностью 3D-путь** — враги летят по сплайну Catmull-Rom: вход пещеры → виражи → спираль вокруг кристалла. Башни стоят на насестах в разных высотах.
2. **Башни = летучие мыши-стражи**, 7 видов:
   - **Визгун** (красный) — быстрые сонар-болты, одиночная цель
   - **Иней** (голубой) — замедление целей
   - **Спора** (зелёный) — дешёвый, яд (DoT)
   - **Эхо** (фиолетовый) — сонар-импульс: раскрывает невидимок + уязвимость (бонус урона)
   - **Жар** (оранжевый) — AoE-взрывы
   - **Фонарь-приманка** — без урона: таунтит врагов к себе, сбивая их с пути (отклонение от маршрута)
   - **Вампир** (тёмный) — дорогой, высокий DPS, лечит Кристалл при убийстве
3. **Слияние (merge)** — две соседние башни одного типа на макс. уровне сливаются в **Альфа-форму** с уникальной пассивкой (цепные выстрелы, вечная аура замедления, расползающийся яд, поле раскрытия, прожигание земли).
4. **Эффект стаи** — соседние башни одного типа дают друг другу +15% урона (мыши сбиваются в стаю).
5. **Фазы луны** (каждые 2-3 волны): Кровавая луна (враги быстрее, +золото), Новолуние (все враги невидимы — нужен Эхо), Полнолуние (+золото, башни сильнее).
6. **Комбо-экономика** — убийства в течение 3 с копят множитель (до ×5), золото растёт; комбо видно в HUD.
7. **6 типов врагов** + 2 босса (паучиха на 5-й волне распадается на паучат; вампир-мотылёк на 10-й бьёт кристалл на 10 ХП).
8. **10 волн + бесконечный режим** со скейлингом; победа после 10-й, дальше — endless.

      state.js           — игровое состояние: эссенция, ХП кристалла, комбо, волна
      events.js          — микро event-bus
      waves.js           — композиции волн, скейлинг, фазы луны
      economy.js         — награды, комбо-множитель, цены, продажа
      towers.js          — статы башен, таргетинг (чистая функция), слияние
      enemies.js         — статы врагов, эффекты (замедление, яд, раскрытие)
    world/
      textures.js        — генератор Canvas-текстур (камень, кристалл, крылья, спрайты)
      cave.js            — пещера: пол, стены, сталактиты, кристалл, свет
      path.js            — 3D-сплайн пути (обёртка над core/math)
      perches.js         — насесты (точки установки башен)
    entities/
      enemy.js           — враги: движение по пути, статы, смерть
      tower.js           — башни: стрельба, стая, апгрейд, слияние
      projectile.js      — болты, пульсы, взрывы
      particles.js       — пул частиц (искры, дым, снежинки, пыль)
      effects.js         — статус-эффекты, всплывающий урон, баннеры
    audio/
      sfx.js             — синтез всех звуков (выстрелы, взрывы, крик, монеты)
      music.js           — генеративная эмбиент-музыка (минор, арпеджио)
    ui/
      hud.js             — верхняя панель: ХП, эссенция, волна, комбо
      menu.js            — старт, поражение, победа
      buildbar.js        — панель выбора башни (иконки на canvas)
      towerpanel.js      — панель выбранной башни: апгрейд/продажа/слияние
  tests/logic.test.mjs   — node --test над core/*

## 4. Экономика и баланс (базовые числа)

- Старт: **120 эссенции**, ХП кристалла **20**.
- Враги (ХП/скорость/награда): мотылёк 60/2.2/8; бронежук 180/1.4/16 (−20% физ. урона); рой 25/3.4/4 (×6); невидимка 90/2.6/20; регенератор 140/2.0/25 (+6 ХП/с); паучиха 1400/0.8/120 (босс, распад ×4 по 120 ХП); вампир-мотылёк 2600/1.5/250 (босс, −10 к кристаллу).
- Скейлинг волн: ХП ×1.18^w, награда ×1.06^w (endless — ×1.22^w).
- Башни (цена/урон/скорость/радиус): Визгун 50/14/0.8с/7; Иней 60/6/1.0с/6; Спора 40/4+яд/1.4с/5.5; Эхо 70/5/2.0с/9; Жар 85/12 AoE/1.6с/6.5; Фонарь 60 (таунт); Вампир 140/22/0.7с/7.
- Апгрейды: 3 уровня, ×1.6-1.8 урона за уровень. Продажа — 70%. Слияние — две соседние макс. уровня → Альфа.
- Комбо: окно 3 с, множитель 1→5, бонус золота +10% за уровень комбо.

## 5. Процедурные ассеты

**Изображения** (Canvas 2D → Texture): камень с шумом Вернона и нормалями-бампом; прожилки кристалла; крылья/тела мышей (градиент + шум); спрайты свечения (radial gradient), вспышки, кольца; иконки башен в UI.
**Меши**: крылья мыши — PlaneGeometry с вершинной анимацией взмаха (sin по времени); враги — комбинации примитивов (мотылёк = конусы+крылья, жук = сфера+панцирь, паучиха = сфера+ногти); пещера — икосаэдры с вершинным шумом, сталактиты-конусы; кристалл — Octahedron + PointLight.
**Звук** (WebAudio): все эффекты синтезируются: выстрелы (square-блипы с питчем по типу), взрыв (noise burst + низкий sine), крик мыши (FM-свип), монеты (арпеджио), таунт (мягкий колокол), босс (расстроенные пилы + noise), музыка (генеративный минорный луп, 90 BPM, фильтрованный шум как «ветер пещеры»).

## 6. Технические детали реализации

- **Путь**: 12 контрольных точек, CatmullRom → 200 сэмплов, расстояние-прогресс (враги двигаются по пройденной дистанции, а не по t — равномерная скорость).
- **Таргетинг**: башня стреляет во врага с максимальным прогрессом по пути (ближайшего к кристаллу) в радиусе; приоритет раскрытых над невидимыми.
- **Фонарь-приманка**: враги в радиусе получают «lure»-состояние: цель = точка фонаря, движение по прямой к ней 2.2 с, затем возврат на путь (продолжение с той же дистанции).
- **Невидимость**: невидимые враги рисуются с прозрачностью 0.15 + лёгкое мерцание; раскрытие — Эхо-импульсом, фонарём или близостью к башне (< 2.5).
- **Эффект стаи**: для каждой башни считать соседей того же типа в радиусе 3.0 → +15% урона за соседа (макс +60%).
- **VFX**: пул частиц (300 шт), всплывающие числа урона (DOM или спрайты), баннеры волн и фаз луны, тряска камеры при уроне кристалла, вспышка экрана.
- **Камера**: орбитальная (drag — вращение, wheel — зум, пределы 14–40), медленный авто-облёт в простое, пауза при blur.
- **Перф**: pixelRatio ≤ 2, один DirectionalLight без теней + PointLight кристалла + 2-3 тёплых, фейковые тени-спрайты; пул геометрий/материалов; `dispose()` при продаже башен.
- **Доступность**: `prefers-reduced-motion` — отключить тряску/автооблёт, кнопка mute, пауза.

## 8. Уровни и механика развития

- **Кампания — 3 уровня** (`src/core/layout.js` → `LEVELS`): волны глобальные 1..10; ур.1 «Преддверие» = волны 1–4, ур.2 «Зал эха» = 5–7 (босс: Паучиха), ур.3 «Сердце пещеры» = 8–10 (босс: Вампир-мотылёк). После победы — бесконечный режим на карте ур.3.
- У каждого уровня свои: трасса (S / зеркальная S / двойная S), насесты, тема света и тумана, набор доступных башен (ур.1: Визгун/Иней/Спора; ур.2: +Эхо/Жар; ур.3: +Фонарь/Вампир).
- **Между уровнями — выбор 1 из 3 улучшений на всю кампанию** (`src/core/upgrades.js`): +40 ◆ стартовой эссенции, +6 макс. ХП кристалла (полный ремонт), +12% урона, −10% цены, +8% скорости перезарядки. Эффекты накапливаются.
- Декор размещается с гарантированным отступом от трассы (`findSpot`/`minDistToPath` в `cave.js`) — путь никогда не пересекает валуны/сталагмиты/друзы; закреплено runtime-тестом для всех уровней.
- Прогресс сохраняется в `localStorage` (лучший уровень/волна/убийства) и показывается в меню.

## 10. Десктоп-путь (на будущее)

Ядро (`src/core/`) не зависит от DOM/WebGL — его можно переиспользовать 1-в-1. Десктоп = Tauri (Rust) или Electron: `tauri init` в этом же репозитории, веб-сборка `dist/` как фронт, без изменений игрового кода. WebAudio и WebGL работают в webview без изменений.
