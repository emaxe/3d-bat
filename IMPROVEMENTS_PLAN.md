# План доработки проекта 3D-BAT

Этот документ описывает выполненные и запланированные улучшения архитектуры, кодстайла и инфраструктуры проекта.

## ✅ Выполнено (Приоритет 1)

### 1. Настройка линтеров и форматеров
- **ESLint 9** с конфигурацией `eslint.config.js`
- **Prettier** для автоматического форматирования
- Правила:
  - `curly`: обязательные фигурные скобки для всех блоков
  - `eqeqeq`: строгое сравнение `===` вместо `==`
  - `no-unused-vars`: запрет неиспользуемых переменных
  - `import/order`: сортировка импортов
  - `max-lines-per-function`: предупреждение для функций >50 строк
  - `max-lines`: предупреждение для файлов >400 строк
  - `no-magic-numbers`: предупреждение для магических чисел (с исключениями)

### 2. Исправление критических ошибок ESLint
- Добавлены фигурные скобки во всех `if/for/else` блоках
- Удалены неиспользуемые переменные
- Исправлен порядок импортов

### 3. Конфигурационные файлы
- `.eslintrc.json` — устаревшая конфигурация (для совместимости)
- `eslint.config.js` — новая плоская конфигурация ESLint 9
- `.prettierrc` — настройки форматирования кода
- `.prettierignore` — игнорирование `dist/` и `node_modules/`

## 📋 В работе (Приоритет 2)

### 4. Рефакторинг game.js (God Object)
**Текущее состояние:** 1012 строк, нарушает Single Responsibility Principle

**План декомпозиции:**
```
src/game.js → src/orchestration/
├── waveManager.js      — управление волнами врагов
├── buildSystem.js      — система строительства башен
├── cameraController.js — управление камерой и вводом
├── inputHandler.js     — обработка жестов и кликов
├── levelManager.js     — загрузка и переключение уровней
└── gameState.js        — управление состоянием игры
```

**Критерии готовности:**
- Каждый модуль <200 строк
- Явные зависимости через конструктор
- Unit-тесты для каждого модуля

### 5. JSDoc аннотации
**Цель:** Добавить типизацию для публичных API

**Приоритетные файлы:**
1. `src/core/*.js` — ядро игры (математика, экономика, волны)
2. `src/entities/*.js` — сущности (башни, враги, снаряды)
3. `src/game.js` — основной оркестратор

**Пример:**
```javascript
/**
 * @param {number} baseDamage - Базовый урон башни
 * @param {number} multiplier - Множитель урона от типа врага
 * @returns {number} Итоговый урон
 */
export function calculateDamage(baseDamage, multiplier) {
  return Math.floor(baseDamage * multiplier);
}
```
